# TaskTracker - Sistema de Gerenciamento de Tarefas

> **Bootcamp II** - Projeto Cumulativo de Desenvolvimento de Software

## Sobre o Projeto
O **TaskTracker** é uma aplicação voltada para a organização e acompanhamento de tarefas diárias, permitindo categorizar atividades por prioridade (Alta, Média e Baixa), definir prazos de entrega e monitorar o status de conclusão.

## Estrutura do Repositório
- `docs/`: Contém a documentação e o planejamento lógico do sistema (Fase 1).
- `src/`: Código-fonte da aplicação desenvolvida em Python.
- `.gitignore`: Configuração para ignorar arquivos temporários do ambiente de desenvolvimento.

## Tecnologias Planejadas
- Python 3
- Git & GitHub
- Google Docs / PDF (Planejamento Lógico)
